1. Project Overview & Research Objectives

1.1 Project Abstract

Modern Network Intrusion Detection Systems (NIDS) are overwhelmingly evaluated under a closed-set classification assumption: every incoming network flow is assumed to belong to one of the known attack families observed during training. In practical deployment, this assumption fails catastrophically when encountering novel zero-day attacks, which closed-set models silently misclassify with high confidence. Furthermore, streaming network traffic experiences persistent concept and distributional drift, causing static confidence thresholds to fail.

This project proposes an end-to-end, three-tier real-time intrusion detection and triage architecture:

  • Tier-1 Fast Detection Cascade: An Isolation Forest anomaly pre-filter combined with a multi-class XGBoost classifier and per-alert TreeSHAP explainability.
  • Open-Set Recalibration & Adaptive Conformal Gating: Adapts OpenMax Extreme Value Theory (EVT) from deep network logits to gradient-boosted decision tree margins, paired with an Adaptive Conformal Inference (ACI) gate that continuously adjusts the escalation threshold to guarantee an operator’s triage budget under non-stationary traffic drift.
  • Tier-2 Budget-Gated LLM Reasoner: Routes escalated, highly uncertain alerts off the streaming hot path to a Retrieval-Augmented Generation (RAG) agent that grounds threat explanations in a curated MITRE ATT&CK knowledge base.

1.2 Core Research Objectives

  • Objective 1: Build a high-throughput, low-latency streaming pipeline using Kafka that processes network flows and extracts sliding-window statistical features in real time.
  • Objective 2: Implement an open-set decision head adapted for tree ensembles that scores out-of-distribution novelty (unknown_mass) to identify zero-day attacks without deep neural network dependencies.
  • Objective 3: Implement an online-adaptive conformal calibration mechanism to dynamically stabilize false-positive escalation rates under severe day-to-day traffic drift.
  • Objective 4: Design and evaluate a budget-gated Tier-2 LLM triage agent with RAG grounding to provide structured root-cause explanations and MITRE ATT&CK attribution while keeping expensive LLM latency off the streaming hot path.

2. Systematic Critical Review of Selected Research Papers

Paper 1: Towards Open Set Deep Networks
A. Bendale and T. E. Boult • CVPR, 2016.
Methodology/Approach: Introduces OpenMax, an open-set alternative to Softmax. OpenMax uses Extreme Value Theory (EVT) to fit per-class Weibull tail distributions over the distances of correctly classified training samples from their class mean activation vectors (MAVs). At test time, activation vectors that fall into the extreme tails of all known classes have their top scores discounted, redistributing the subtracted probability mass to an explicit 'unknown' class logit.
Dataset: ILSVRC 2012 (ImageNet) benchmark.
Key Findings: Standard deep networks assign dangerously high Softmax confidence (>0.99) to completely unrecognized, out-of-distribution images. OpenMax successfully identifies novel classes while maintaining high classification accuracy on known classes.
Limitations: The formulation relies strictly on continuous penultimate-layer logit vectors from deep neural networks and requires substantial numbers of training samples per class to fit stable Weibull parameters. It provides no mechanism to control an operator's operational inspection budget in streaming environments.
Research Gap/Relevance: Our project adapts the core EVT Weibull-tail recalibration mechanism from neural network logits to gradient-boosted tree margins (XGBoost), enabling open-set zero-day detection on tabular network flow features without deep learning overhead.
Paper 2: Adaptive Conformal Inference Under Distribution Shift
I. Gibbs and E. Candès • NeurIPS, 2021.
Methodology/Approach: Formulates Adaptive Conformal Inference (ACI), an online algorithm that dynamically adjusts the non-conformity significance level α_t at each step based on the error of the preceding step: α_{t+1} = α_t + γ(α* - err_t). This continuously recalibrates prediction intervals without requiring data exchangeability or stationary distributions.
Dataset: Non-stationary time-series data, epidemiological COVID-19 case tracking, and macroeconomic benchmarks.
Key Findings: Proves theoretically and empirically that standard static split-conformal prediction fails under temporal drift, whereas ACI provably achieves long-run asymptotic target coverage even under adversarial distribution shifts.
Limitations: Focuses exclusively on one-dimensional continuous prediction intervals and scalar regression/classification tasks; not evaluated within high-throughput cybersecurity pipelines or multi-class alert gating systems.
Research Gap/Relevance: Our project directly integrates the ACI update rule into an Adaptive Conformal Gate that controls the threshold on open-set unknown_mass. This ensures that the system escalates no more than an operator’s fixed triage budget (e.g., 10%) even across multi-day network traffic drift.
Paper 3: Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks
P. Lewis et al. • NeurIPS, 2020.
Methodology/Approach: Proposes RAG, a hybrid architecture combining a pre-trained parametric sequence-to-sequence model with a non-parametric Dense Passage Retriever (DPR) over a vector database index (Wikipedia). The model conditions generation on dynamically retrieved context passages.
Dataset: Natural Questions, TriviaQA, CuratedTREC, and Jeopardy question answering.
Key Findings: RAG dramatically reduces hallucinations, outperforms ungrounded parametric models on domain-specific factual tasks, and allows knowledge bases to be updated dynamically without retraining the base language model.
Limitations: Assumes high-latency multi-billion parameter neural embedding pipelines (e.g., DPR/FAISS) that are computationally prohibitive if placed on streaming hot paths.
Research Gap/Relevance: We adopt the RAG paradigm for automated security triage, replacing dense neural retrievers with a lightweight TF-IDF cosine similarity engine over a curated MITRE ATT&CK technique corpus, keeping the LLM off the hot path and invoking it only for escalated alerts.
Paper 4: Toward Generating a New Intrusion Detection Dataset and Intrusion Traffic Characterization
I. Sharafaldin, A. H. Lashkari, and A. A. Ghorbani • ICISSP, 2018.
Methodology/Approach: Introduces a comprehensive methodology for creating realistic network intrusion datasets, establishing the CICFlowMeter feature extraction tool to extract over 80 statistical bidirectional flow features (inter-arrival times, packet length statistics, flag counts, sub-flow metrics) and generating CICIDS2017 and CSE-CIC-IDS2018.
Dataset: CICIDS2017 multi-day network captures containing benign traffic and seven attack scenarios (Brute Force, Heartbleed, Botnet, DoS, DDoS, Web Attacks, Infiltration).
Key Findings: Modern NIDS evaluation requires realistic background protocol distributions, complete multi-day capture profiles, and diverse attack vectors.
Limitations: The raw CSV releases contain documented timestamp parsing issues (day-first vs. month-first anomalies), duplicate flow bursts that cause evaluation leakage under random splitting, and severe class imbalance in rare categories (Infiltration, Heartbleed).
Research Gap/Relevance: Serves as the primary real-world tabular dataset benchmark for training and evaluating our two-stage detector and leave-one-family-out (LOFO) zero-day trials.
Paper 5: XGBoost: A Scalable Tree Boosting System
T. Chen and C. Guestrin • KDD, 2016.
Methodology/Approach: Introduces a scalable end-to-end tree boosting algorithm utilizing weighted quantile sketch for approximate split finding, a sparsity-aware split finding algorithm for missing values, and a cache-aware block structure for parallel computation.
Dataset: HIGGS, Allstate-10M, Yahoo Learning to Rank.
Key Findings: XGBoost provides superior tabular classification accuracy while executing more than an order of magnitude faster than existing tree ensembles.
Limitations: Inherently a closed-set classifier; produces unnormalized margin outputs rather than well-calibrated posterior probabilities and silently misclassifies novel inputs with high confidence.
Research Gap/Relevance: Deployed as our Stage-2 Attack Classifier, whose unnormalized raw margins (output_margin=True) serve as the direct input to our OpenMax EVT recalibration head.
Paper 6: Isolation Forest
F. T. Liu, K. M. Ting, and Z.-H. Zhou • IEEE ICDM, 2008.
Methodology/Approach: Proposes an unsupervised anomaly detection method based on ensemble isolation trees (iTrees). It recursively partitions feature space at random; anomalies require significantly fewer partitions to isolate, resulting in shorter average tree path lengths.
Dataset: HTTP, Forest Cover, Breast Cancer, Satellite datasets.
Key Findings: Demonstrates linear time complexity O(n) with a small memory footprint, scaling far better than density-based (LOF) or distance-based (k-NN, One-Class SVM) detectors on high-dimensional streams.
Limitations: Only produces a continuous anomaly score; cannot identify specific attack categories, provides no explainability, and requires fine-tuning of the contamination parameter per traffic distribution.
Research Gap/Relevance: Deployed as our Stage-1 Anomaly Pre-Filter, cheaply discarding the vast majority of benign traffic to conserve computational resources.
Paper 7: A Unified Approach to Interpreting Model Predictions
S. M. Lundberg and S.-I. Lee • NeurIPS, 2017.
Methodology/Approach: Unifies multiple feature attribution frameworks under SHAP (SHapley Additive exPlanations), grounding model interpretation in cooperative game theory. Formulates TreeSHAP, computing exact Shapley values for tree ensembles in polynomial time O(TLD^2).
Dataset: NHANES I epidemiological survey and UCI benchmark datasets.
Key Findings: TreeSHAP is the only feature attribution method that satisfies both local accuracy and consistency guarantees simultaneously.
Limitations: Standard external Python implementations introduce serialization incompatibilities with modern multiclass XGBoost models and add latency overhead if computed indiscriminately across every flow.
Research Gap/Relevance: Integrated natively into our inference pipeline via XGBoost’s built-in prediction contribution engine, attaching top-k feature attribution vectors to every published Kafka alert.
Paper 8: Towards a Standard Feature Set for Network Intrusion Detection System Datasets
M. Sarhan, S. Layeghy, and M. Portmann • IEEE TNSM, 2022.
Methodology/Approach: Analyzes feature incompatibility across popular NIDS datasets (CIC-IDS2018, UNSW-NB15, ToN-IoT) and converts multiple raw PCAP sources into a standardized 43-feature NetFlow-v2 (NF-v2) schema.
Dataset: NF-CSE-CIC-IDS2018-v2, NF-UNSW-NB15-v2, NF-ToN-IoT-v2, NF-BoT-IoT-v2.
Key Findings: Models trained on proprietary feature sets (such as CICFlowMeter or Argus) cannot be evaluated across datasets; standardizing features allows true cross-dataset performance assessment without sacrificing detection accuracy.
Limitations: Evaluated only closed-set classification models; did not explore open-set zero-day generalization across different network topologies.
Research Gap/Relevance: Establishes the foundational theoretical reason why cross-dataset NIDS generalization is difficult and defines the standard feature-mapping methodology for future cross-domain validation.
Paper 9: OpenAUC: Towards AUC-Oriented Open-Set Recognition
Z. Wang et al. • NeurIPS, 2022.
Methodology/Approach: Identifies a fundamental flaw in using standard AUROC for open-set evaluation (which only measures whether unknown samples receive higher novelty scores than known samples, regardless of whether known samples were classified correctly). Proposes OpenAUC, which strictly requires joint closed-set classification correctness and open-set novelty separation.
Dataset: CIFAR-10, CIFAR-100, TinyImageNet.
Key Findings: Standard AUROC severely overestimates open-set performance when closed-set classification errors exist. OpenAUC provides an unambiguous, holistic evaluation metric.
Limitations: Formulated and benchmarked exclusively on computer vision datasets; unverified on tabular streaming cybersecurity datasets.
Research Gap/Relevance: Incorporated into our experimental evaluation harness (ids_ml/evaluation.py) to benchmark leave-one-family-out zero-day trials alongside standard AUROC.
Paper 10: DQN-IDS: A Deep Reinforcement Learning-based Intrusion Detection System for Edge Networks
SDIoTSec Working Group • NDSS SDIoTSec Workshop, 2026.
Methodology/Approach: Explores reinforcement learning (Deep Q-Networks) and lightweight CNN architectures for sub-millisecond network traffic classification on resource-constrained edge hardware.
Dataset: CICIDS2017, BoT-IoT.
Key Findings: Establishes strict latency protocols for evaluating real-time NIDS: demonstrates that single-flow streaming latency (batch size = 1) is dominated by per-call runtime overhead and is orders of magnitude slower than batched throughput.
Limitations: Implements closed-set classification only; lacks explainability mechanisms and post-detection analyst triage workflows.
Research Gap/Relevance: Provides the benchmark latency measurement protocol used in our project to quantify the 68x performance gap between single-flow streaming latency (9.67 ms) and batched throughput (7,116 flows/sec).

3. Systematic Literature Review Synthesis

3.1 What Has Already Been Studied?

Research in Machine Learning-based Network Intrusion Detection Systems (NIDS) spans over two decades. Foundational studies established statistical feature extraction methods (Sharafaldin et al., 2018) to represent bidirectional network flows. Prior work has concentrated heavily on supervised classification algorithms, including Random Forests, XGBoost (Chen & Guestrin, 2016), and Multi-Layer Perceptrons. In parallel, unsupervised anomaly detection techniques such as Isolation Forests (Liu et al., 2008) and One-Class Support Vector Machines (OC-SVM) have been widely investigated for identifying abnormal traffic volumes. More recently, post-hoc Explainable AI (XAI) frameworks, specifically TreeSHAP (Lundberg & Lee, 2017), have been adopted to interpret model predictions for security analysts.

3.2 What Approaches Have Been Used?

  • Pipelined Multi-Stage Filtering: Combining a cheap initial anomaly filter (e.g., Isolation Forest) with an expensive multi-class classifier to reduce computation.
  • Open-Set Recalibration: Employing Extreme Value Theory (OpenMax; Bendale & Boult, 2016) or Energy-based scoring to identify samples outside training distributions.
  • Conformal Risk Control: Applying static split-conformal calibration (Vovk et al., 2005; Angelopoulos & Bates, 2021) to place distribution-free error bounds on model outputs.
  • LLM-Based Security Agents: Leveraging Large Language Models (LLMs) as autonomous agents or generative classifiers to interpret raw network packets and security alerts.

3.3 What Are the Major Findings Across the Literature?

  • Class Imbalance & Rare-Attack Collapse: While supervised models consistently achieve >99% F1-score on high-volume attack classes (e.g., DoS, PortScan), their recall severely collapses on rare, subtle categories (e.g., Infiltration, Web Attacks), where support is minimal.
  • Evaluation Data Leakage: Random train/test splits artificially inflate performance metrics due to bursty, duplicate flow records generated during cyber-attack simulations; time-based chronological splitting is mandatory for honest evaluation.
  • RAG Efficacy in Technical Domains: Grounding LLM inference in external technical documentation (Lewis et al., 2020) reliably eliminates hallucinated technique IDs and produces consistent MITRE ATT&CK attributions.

3.4 What Limitations and Research Gaps Remain?

  1. The Closed-Set Fallacy: The vast majority of production-oriented NIDS assume that all future network traffic belongs to the closed set of classes seen during training. When presented with a novel zero-day attack, closed-set classifiers silently force-fit the flow into a known class with high confidence.
  2. Calibration Collapse Under Concept Drift: Static conformal calibration assumes exchangeability between calibration and deployment data. In live networks, normal traffic and attack patterns continuously drift over time. Under real drift, static thresholds collapse, resulting in either complete alert suppression or severe over-escalation.
  3. The LLM Real-Time Bottleneck: Recent attempts to introduce LLMs into intrusion detection (e.g., MA-IDS) place the language model directly on the high-speed hot path (calling the LLM on every incoming flow). Because cloud LLM calls exhibit latencies of 25–60 seconds per request and strict rate limits, running LLMs on every flow renders real-time operation impossible.

3.5 How Does Our Proposed Project Address the Identified Gaps?

  • Margin-Based Tree OpenMax (H1): We adapt OpenMax from deep neural networks to XGBoost’s raw margin outputs (ids_ml/openset_head.py), enabling tree ensembles to compute explicit unknown_mass scores and catch novel zero-day attacks without deep learning dependencies.
  • Adaptive Conformal Inference (ACI) Escalation Gate (H2): We implement Gibbs & Candès’ online ACI update rule within an AdaptiveConformalGate (ids_ml/adaptive_conformal_gate.py). By updating the non-conformity threshold online after every observed flow, our system dynamically holds an operator’s exact triage budget (e.g., 10%) with ≈100× lower error than static calibration under real multi-day drift.
  • Budget-Gated Tier-2 RAG Reasoner (H3): We offload LLM reasoning entirely from the streaming hot path into an asynchronous Tier-2 service (tier2_reasoner/). The LLM is invoked only for the small fraction of flows marked escalated: true by the conformal gate. It uses lightweight TF-IDF retrieval over curated MITRE ATT&CK technique descriptions, achieving 100% technique attribution accuracy (McNemar p = 0.0039) while maintaining sub-10ms Tier-1 streaming throughput.
